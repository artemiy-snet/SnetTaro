# SnetTaro

Навчальний тренажер Таро — інтерактивний застосунок для роботи з архетипами й структурованої саморефлексії. Психологічний підхід, без містичної подачі: колода як інструмент проєктивного мислення, а не передбачення майбутнього.

Встановлюється як застосунок на телефон (PWA) — без App Store чи Google Play.

## Можливості

### Колода й тлумачення
- **Повна колода** — 78 карт (22 Старші + 56 Молодших Аркан)
- Для кожної карти: сюжет, пряме й перевернуте значення, **альтернативний погляд** (інший кут — стосунки, робота, побут) і ключові асоціації
- Власні лінійні SVG-ілюстрації для кожної карти — колір символу передає стихію масті (вогонь/вода/повітря/земля)

### Розклади
Сім типів розкладу на вибір:
- 1 карта — Відповідь
- 3 карти — Минуле · Теперішнє · Майбутнє
- 3 карти — Розум · Тіло · Дух
- 5 карт — Вибір між двома шляхами
- 6 карт — Стосунки
- 7 карт — Підкова
- 10 карт — Кельтський хрест

Перед розкладом можна сформулювати питання — воно супроводжує весь процес і підсумок.

### Взаємодія
- **Віяло карт** — горизонтальна прокрутка, тап по картці витягує її з колоди
- **Уточнення** — будь-яку витягнуту карту можна доуточнити додатковими картами (і вкладено теж)
- **Особисті нотатки** — до кожної карти можна записати власну асоціацію

### Підсумок розкладу
- **Повна розшифровка** — не просто список назв, а значення кожної карти, альтернативний погляд, нотатки й уточнення в одному місці
- **Аналіз спільних тем** — старші/молодші аркани, повторювані масті й числа, перевернуті карти
- **Прочитати як оповідання** — той самий розклад, зібраний у зв'язний текст
- **Історія сесії** — усі розклади поточної сесії доступні для перегляду

### ШІ-аналіз (опційно, з власним ключем)
- Кнопка **«🔮 Глибокий аналіз (ШІ)»** передає весь розклад (карти, позиції, орієнтації, уточнення, нотатки) моделі Claude, яка пише повний, зв'язний розбір — зі структурними патернами, наскрізними нитками між картками й цілісним сюжетом наприкінці
- Далі можна **вести розмову** — ставити уточнювальні питання про розклад прямо в чаті
- **Голос** — питання можна поставити мікрофоном (розпізнавання мовлення), а відповіді Claude озвучуються вголос, з підсвіткою слова, яке зараз читається
- Працює напряму з браузера на власний API-ключ Anthropic (кнопка «ШІ» вгорі) — без сервера-посередника; ключ зберігається лише на пристрої

### Оформлення колоди
- Кнопка **«Колода»** — можна замінити символ будь-якої карти власним фото. Застосунок сам вписує фото в рамку, підписує назву й додає значок масті — без ручної обробки
- Або можна покласти готові зображення у папку `cards/` на сайті (див. `cards/README.md`) — тоді вони будуть доступні для всіх відвідувачів сайту, а не лише в одному браузері

### Офлайн-режим
Після першого відкриття застосунок працює без інтернету (service worker), крім функцій, що вимагають мережі (ШІ-аналіз).

## Встановлення на телефон

1. Відкрий посилання на застосунок у Chrome (Android) або Safari (iOS)
2. Android: меню (⋮) → **«Додати на головний екран»**
   iOS: кнопка «Поділитися» → **«На екран Домівки»**
3. Готово — SnetTaro відкривається як звичайний застосунок, на весь екран, з іконкою

## Технічно

Статичний сайт, без бекенду й збірки:

- `index.html` — весь застосунок (HTML/CSS/vanilla JS, single file)
- `manifest.json` — маніфест PWA (назва, іконки, кольори)
- `sw.js` — service worker для офлайн-кешування (network-first)
- `icon-192.png`, `icon-512.png`, `icon-512-maskable.png` — іконки застосунку
- `cards/` — опційна папка для власних зображень карт (див. `cards/README.md` за списком точних назв файлів)

Дані (розклади, нотатки, історія сесії) зберігаються лише в пам'яті поточної сесії браузера. Завантажені через застосунок фото карток і налаштування ШІ (API-ключ, модель) зберігаються в IndexedDB — постійно, але лише на цьому пристрої й у цьому браузері. Нічого з цього не передається нікуди, крім прямих запитів до Anthropic під час ШІ-аналізу.

## ШІ-функції: як під'єднати

1. Заведи акаунт на [console.anthropic.com](https://console.anthropic.com/settings/keys), поповни баланс, створи API-ключ
2. У застосунку: кнопка **«ШІ»** вгорі → встав ключ → обери модель (Haiku — швидше й дешевше, Sonnet — глибше) → «Зберегти»
3. Заповни будь-який розклад → «Показати підсумок» → «🔮 Глибокий аналіз (ШІ)»

Оскільки сайт публічний, будь-хто, хто на нього зайде, може ввести свій власний ключ — використання завжди йде за рахунок ключа, який введений у конкретному браузері, а не спільного.

## Локальний запуск / хостинг

Достатньо будь-якого статичного хостингу (GitHub Pages, Netlify, Vercel тощо) — файли просто мають лежати в одній папці. Офлайн-режим і встановлення працюють лише через `https://` (або `localhost`), не через відкриття файлу напряму.
